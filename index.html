2.2 Mi primer repositorio

Con git init creé la carpeta oculta .git.

Estados: untracked, modified, staged y unmodified.

2.3 Ciclo de vida

  1. Editar el archivo
  2. Revisar con git status
  3. Preparar con git add
  4. Guardar con git commit

2.4 Exclusión con .gitignore

Ignoro secretos, registros y archivos temporales.

*.log

3.1 Ramas

Una rama es un puntero a un commit: trabajo en paralelo sin tocar main.

git switch -c feature/nueva-idea

3.2 Fusiones

Fast-forward, fusión de tres vías, squash y rebase integran el trabajo de las ramas.

git merge feature/nueva-idea

2.1 Instalación y configuración

Instalé Git y configuré mi identidad.
